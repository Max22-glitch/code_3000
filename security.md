# Repository Security

## Intended Users

This repository is intended for me, my instructor, and other authorized members of my class who may need to view or review the code and coursework contained in the repository.

## Security Risk Assessment

The security risk associated with this repository is relatively low because it primarily contains coursework and code created for class assignments. The repository should not contain passwords, API keys, authentication tokens, or other sensitive personal information. However, unauthorized modification of the repository could affect the integrity of my assignments or introduce malicious or incorrect code.

## Security Measures

I have taken steps to protect the repository by using GitHub repository rules and pull request protections. The default branch is protected by an active ruleset that restricts certain changes and uses pull requests and code-owner review. These protections help prevent unauthorized or accidental changes from being merged into the repository.

I will also avoid committing sensitive information such as passwords, API keys, access tokens, or private personal information to the repository.
